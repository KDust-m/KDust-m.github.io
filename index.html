Fortune Cheatkey Uploader

Fortune Cheatkey Uploader is a personal publishing tool used by 은하 운세소 (Galaxy Oracle Studio), the creator of @galaxy.oracle_studio on TikTok, YouTube and Instagram. Every day it takes short vertical videos that the creator produced in advance (daily horoscope content: zodiac sign and Chinese zodiac rankings) and posts them to the creator's own accounts, using the caption and hashtags the creator wrote:

  • TikTok — through the TikTok Content Posting API
  • YouTube — as YouTube Shorts, through the YouTube API Services (YouTube Data API v3)
  • Instagram — as Reels, through the Instagram Graph API

How it works

  1. The creator signs in to each platform and authorizes the tool: TikTok Login Kit (user.info.basic, video.publish), Google OAuth 2.0 (youtube.upload, youtube.readonly), and Facebook Login (instagram_basic, instagram_content_publish).
  2. The tool shows which account or channel is connected.
  3. The creator chooses the videos and the privacy level. The tool uploads the video files with their titles, descriptions and captions.
  4. The tool checks the publishing result and records which videos were posted so the same video is not posted twice.

The tool only posts to the accounts of the creator who authorized it. It does not read, collect or post to any other user's account. See our Privacy Policy and Terms of Service.
